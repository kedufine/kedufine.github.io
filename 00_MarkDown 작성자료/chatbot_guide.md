# K-에듀파인 챗봇 사용자 매뉴얼

## 개요
K-에듀파인 챗봇은 업무관리를 사용하면서 생기는 궁금증을 AI가 즉시 답변해 주는 상담 서비스입니다.
회원가입과 로그인을 마치면 상담 화면에서 질문을 입력할 수 있고, 챗봇은 참고 문서를 근거로 답변을 생성합니다.
챗봇이 답변하지 못하는 질문은 게시판을 통해 상담원에게 전달되며, 상담원이 직접 답변합니다.

!!! Info "시험운영 안내"
    - 시험운영기간: **2026년 9월 ~ 12월**
    - 상담 가능 범위: **업무관리**(서비스공통 포함)
    - 학교회계 등 그 밖의 업무 분야는 현재 서비스 미제공 상태이며, 이후 상황에 따라 확대 예정
    - 텍스트 질문·답변만 지원하며, 파일이나 이미지를 첨부하는 기능은 없음

``` mermaid
graph LR
  A[회원가입 및 로그인] --> B[질문영역 선택];
  B --> C[질문 입력];
  C --> D{챗봇 답변};
  D -->|답변 생성| E[답변 및 참고 문서 확인];
  D -->|답변 불가| F[게시판 이관];
  F --> G[상담원 직접 답변];
```


## 홈 화면
홈 화면은 상담을 시작할 업무 영역을 선택하고, 회원가입과 로그인을 수행하는 첫 화면입니다.
회원가입과 로그인을 마쳐야 챗봇을 사용할 수 있으며, 상담 이력은 가입한 사용자를 기준으로 저장됩니다.


### :material-view-dashboard: 질문영역
상담을 진행할 업무 영역을 선택하는 영역입니다.
영역별로 상담 가능 여부가 표시되므로, 상담 가능한 영역을 정확히 선택해야 정확한 답변을 받을 수 있습니다.

- 각 영역별 이름 및 상담 가능 범위 확인 가능
- 클릭 시 상담 화면으로 이동
- 로그인하지 않은 상태에서 클릭 시 로그인 창 호출


### :material-login: 로그인
회원가입 시 설정한 ID와 Password를 입력하여 로그인한 후 상담을 시작합니다.
로그인하지 않은 상태에서는 상담 이력이 저장되지 않습니다.


### :material-account-plus: 회원가입
회원가입 버튼을 클릭하면 호출되는 창에서 기관, 닉네임, ID, Password를 설정하여 가입합니다.
ID는 중복 확인을 거쳐야 하며, Password는 확인 입력란에 동일하게 한 번 더 입력해야 합니다.

!!! Info "회원가입 입력 항목"

    | 항목     | 입력 규칙                              |
    | -------- | -------------------------------------- |
    | 기관     | 교육청, 직속기관, 학교, 유치원 중 선택 |
    | 닉네임   | 한글, 영문, 숫자 20자 이내             |
    | ID       | 영문, 숫자, 하이픈(-) 20자 이내        |
    | Password | 영문, 숫자, 특수문자 포함 8자 이상     |

!!! Warning "개인정보관리 기능 미제공"
    시험운영기간에는 별도의 본인인증이 없는 간편 가입 형식이므로 닉네임 변경, 비밀번호 재설정 등 개인정보관리 기능 제공 없음.

    비밀번호를 잊었거나 닉네임을 변경하려는 경우 새로 회원가입 진행 필요.


## 상담 화면
상담 화면은 챗봇에게 질문을 입력하고 답변을 확인하는 공간입니다.
동일한 창에서 상담을 지속하는 경우 챗봇이 이전 상담 내용을 참고하여 답변하므로, 하나의 주제를 이어서 깊이 있게 물어볼 때 유리합니다.


### :material-message-text: 질문과 답변
화면 중앙의 대화 영역에서 질문을 입력하고 챗봇의 답변을 확인하는 기능입니다.

#### 질문 입력 창
화면 하단의 입력 창에 내용을 입력한 후 전송하면 답변이 생성됩니다.

- 좌측 **?** 아이콘 클릭 시 추천 질문 표출
- 입력 창에서 줄바꿈은 ++shift+enter++ 로 입력

#### 참고 문서
답변을 생성할 때 근거로 사용한 문서를 확인하는 영역입니다.

- 펼치기 클릭 시 답변 생성에 사용된 참고 문서 및 내용 확인 가능
- 문서명 클릭 시 파일 다운로드 가능

#### 연관 질문
답변 하단에 직전 질문과 연관된 다른 질문이 표출됩니다.
표출된 문구를 클릭하면 해당 내용을 자동으로 질문하므로, 직접 입력하지 않고도 이어지는 답변을 받을 수 있습니다.

#### 좋아요/오류보고
제시된 답변의 만족 또는 불만족 여부를 체크하는 기능입니다.

- 필요 시 추가 의견을 작성하여 전달 가능
- 전달된 의견은 챗봇 운영진이 검토한 후 지식을 보완하여 답변 품질을 높이는 데 활용

#### 상담원 답변 받기
현재 창에서 진행한 상담 전문을 상담원에게 전달한 후 상담원의 답변을 받는 기능입니다.


### :material-history: 사이드바와 상담 이력
좌측 사이드바에서 화면 이동, 새 상담 시작, 지난 상담 이력 조회를 수행합니다.

#### 홈
클릭 시 홈 화면으로 이동합니다.

#### 사이드바 접기/펼치기
좌측 사이드바를 접거나 펼칠 수 있습니다.
사이드바를 접어둔 경우 새 상담 버튼이 **+** 버튼으로 축약되어 표출됩니다.

#### 온라인 사용자교육자료
온라인 사용자교육자료와 업무관리 초급 매뉴얼로 이동하는 바로가기입니다.

- 클릭 시 관련 사이트로 이동
- 이동한 사이트에서 문서 확인 및 다운로드 가능

#### 새 상담
현재 창이 아닌 새 창에서 상담을 진행합니다.
주제가 다른 질문을 시작할 때 새 상담으로 진행하면 대화 이력이 주제별로 구분되어 관리가 편리합니다.

#### 상담 이력 목록
이전에 진행한 상담 이력의 목록입니다.

- 목록 클릭 시 해당 상담 창을 불러와 내용 확인 가능
- 상단 대화 검색 창에서 이력 검색 가능
- 필요 시 이력 제목 변경 및 삭제 가능


## 게시판 이관
챗봇이 질문에 답변하지 못하는 경우, 게시판을 통해 상담원에게 상담 내용을 전달할 수 있습니다.
전달된 내용은 상담원이 검토한 후 직접 답변하므로 답변을 받기까지 시간이 걸립니다.


### :material-send: 상담원에게 전달
챗봇이 답변하지 못한 경우, 상담 화면에 상담원에게 전달할 수 있는 버튼이 표출됩니다.

`대화내용 전달`

:   챗봇과 주고받은 상담내용을 그대로 상담원에게 전달

`의견 추가 전달`

:   상담내용에 사용자의 의견을 추가로 기재하여 함께 전달

`괜찮아요`

:   상담원에게 전달하지 않고 상담 종료


### :material-check-circle: 상담원 답변 확인
상담원의 답변이 완료되면 상담을 진행했던 창에서 그대로 답변을 확인합니다.

#### 답변 완료 표시
- 상담원 답변이 완료된 시점에 사용자가 해당 상담 창에 접속하지 않은 경우, 상담 이력 우측에 노란색 점 표시
- 상담 창에서 답변을 확인하면 표시 사라짐

#### 게시판 답변 확인
- 상담원 답변 완료 시 챗봇 답변과 동일하게 채팅창에서 완료된 답변 확인 가능
- 우측 하단 상담원 아이콘 클릭 시 상담원에게 추가 질의 가능
- 상담원 답변에 이어서 질문을 입력하면 추가 내용이 상담원에게 전달되어 추가 답변 수신 가능


## 챗봇 사용 FAQ

### :material-account-key: 가입과 서비스 범위

!!! question "로그인 비밀번호를 잊어버렸는데 어떻게 하나요? 닉네임을 바꾸고 싶어요."
    시험운영기간(26.9월~12월)에는 회원가입 시 별도의 본인인증이 없는 간편 가입 형식이기 때문에, 닉네임·비밀번호 변경 등 개인정보관리 기능을 제공하지 않습니다.
    불편하시더라도 새로 회원가입을 진행하여 챗봇을 사용해 주세요.

!!! question "업무관리 말고 다른 업무는 챗봇을 사용할 수 없나요?"
    시험운영기간(26.9월~12월)에는 업무관리(서비스공통 포함)만 운영합니다.
    이후 상황에 따라 K-에듀파인의 학교회계 등 다른 업무 분야로 확대할 예정입니다.

!!! question "챗봇 답변이 너무 느려요."
    K-에듀파인 AI 챗봇은 구글 제미나이 모델을 사용하고 있습니다.
    제미나이 운영 서버의 상황에 따라 답변이 느려질 수 있다는 점 양해 부탁드립니다.

!!! question "AI 챗봇에 파일이나 캡쳐 등을 올릴 수 있나요?"
    K-에듀파인 AI 챗봇은 텍스트로만 질문과 답변이 가능합니다.
    파일이나 이미지 등을 첨부하여 질문하는 기능은 제공하지 않습니다.


### :material-chat: 챗봇 사용 방법

!!! question "대화 입력창에서 줄바꿈을 하고 싶어요."
    대화 입력창에서 줄바꿈은 ++shift+enter++ 로 가능합니다.

!!! question "하단 대화 입력창 위의 추천 질문은 어떤 기준으로 표시되나요?"
    하단 추천 질문은 선생님들이 자주 물어보는 질문을 기준으로 표시됩니다.
    질문의 빈도수에 따라 추천 질문은 업데이트될 수 있습니다.
    원하시는 질문이 추천 질문에 있다면, 채팅창에 직접 입력하지 않아도 추천 질문을 클릭하여 답변을 받을 수 있습니다.

!!! question "하단 추천 질문이 안 보여요."
    추천 질문은 챗봇에 처음 로그인하거나 우측 `[+ 새 상담]`을 클릭했을 때 표시되고, 질문과 답변이 진행되면 사라집니다.
    하지만 대화 입력창 왼쪽 **?** 아이콘을 클릭하면 언제든지 추천 질문을 표시할 수 있습니다.

!!! question "이전에 챗봇과 대화했던 내용을 확인할 수 있나요?"
    가능합니다. 왼쪽 사이드바에 표시되는 대화 목록을 클릭하면 언제든지 이전에 챗봇과 대화했던 내용을 확인할 수 있으며, 필요하면 이어서 질문을 할 수도 있습니다.
    또한 대화 검색 창을 통해 원하는 대화 이력을 검색할 수도 있습니다.

!!! question "기존 질문과 관련없는 새 질문을 하고 싶습니다. 우측 [+ 새 상담]을 클릭해서 질문하면 될까요?"
    우측 `[+ 새 상담]`을 클릭하여 질문을 새로 시작하거나, 기존 질문·답변 창에 이어서 질문해도 상관없습니다.
    다만 우측 `[+ 새 상담]`으로 새로 시작하면 왼쪽의 대화이력에 새로운 대화가 생성되므로, 주제별로 이력을 관리하기에 편리합니다.


### :material-lightbulb-on: 답변 품질 높이기

!!! question "원하는 답변을 얻기 위한 효과적인 질문 방법은 어떤 것일까요?"
    구체적인 질문이 구체적인 답변을 가능하게 합니다.
    예를 들어 "권한은 어떻게 부여하나요?"라는 질문보다 "새로 전입 온 선생님에게 업무관리 기본권한을 부여하는 방법은 어떻게 되나요?"가 훨씬 정확한 답변을 받을 수 있는 질문 방식입니다.
    K-에듀파인 메뉴 명칭이나 버튼 명칭 등 정확한 용어를 곁들여서 질문하는 방법이 매우 효과적입니다.
    또한 질문 형식에 어려움을 겪는다면, 추천 질문이나 답변 후 제시되는 연관 질문의 형식을 참고해 보시기 바랍니다.

!!! question "답변이 너무 간단합니다. 더 자세한 답변을 받을 수 있을까요?"
    답변이 너무 간략해서 도움이 되지 않았다면 이어서 다음과 같이 질문해 보세요.

    - "조금 더 자세히 설명해 줄 수 있어?"
    - "구체적인 절차를 곁들여 설명해 줘."
    - "차이점을 비교해서 다시 설명해 줘."

    AI 챗봇은 이전 대화 이력을 바탕으로 보다 자세한 답변을 해 줄 수 있습니다.

!!! question "질문을 명확히 했는데도 답변이 만족스럽지 않습니다. 어떻게 보완할 수 있을까요?"
    AI 챗봇은 답변과 함께 참고 문서를 보여줍니다.
    참고 문서에도 원하시는 답변 지식이 없다면, 하단의 **오류보고** 아이콘(손가락 모양)을 클릭하여 답변 만족도 의사를 표시하고 간략한 의견을 남겨 주세요.
    해당 내용은 챗봇 운영진에서 검토하고 필요 시 빠르게 지식을 보완하여 답변 품질을 높이는 데에 활용됩니다.


### :material-headset: 상담원 답변 요청

!!! question "챗봇에서 답변을 할 수 없으며 상담원에게 답변을 요청할 수 있다고 나옵니다. 이 기능은 어떻게 사용하나요?"
    챗봇이 답을 하지 못하는 경우, 관련한 답변을 상담원에게 받을 수 있는 기능입니다.
    하단의 `[대화내용 전달]` 버튼은 상담원에게 챗봇과 대화한 해당 내용을 전달하며, `[의견 추가 전달]` 버튼은 대화 내용에 추가로 의견을 기재하여 함께 전달하는 기능입니다.
    전달이 필요 없을 땐 `[괜찮아요]` 버튼으로 대화를 종료할 수 있습니다.
    전달된 내용은 상담원이 검토 후 직접 답변하며, 답변이 완료되면 같은 챗봇 창에서 상담원 답변을 확인할 수 있습니다.

!!! question "상담원 직접 답변을 받았습니다. 해당 답변에 추가로 질문을 하는 방법은 무엇인가요?"
    상담원 답변에 이어서 질문을 입력하면 추가 내용이 상담원에게 전달되어 추가 답변을 받을 수 있습니다.
