## 2026년 10월 27일

??? success "[과제카드] 과제카드 담당자일괄처리 탭 우선순위 변경"
	- 과제카드함 화면의 담당자일괄처리 팝업에서 담당자 탭을 우선 배치하여 담당자, 관리자, 내부관계자 순으로 탭이 보여지도록 개선
??? success "[과제카드] 과제카드 관리자 및 내부관계자 자동지정 기능 개선"
	1. 과제카드 관리자 자동 승격 삭제 및 부재 알림 기능 추가
		- 인사이동이나 조직 개편으로 부서의 과제카드 관리자가 공석이 될 때, 부서 내 과제카드 담당자가 관리자로 자동 승격되지 않도록 개선
		- 공석 발생 시 해당 부서(학교)과제카드담당자 권한 사용자에게 관리자 신규 지정 안내 메일 및 알림이 자동으로 발송되도록 기능 추가
	2. 과제카드 내부관계자의 인사이동 시 권한 자동 정리
		- 과제카드 내부관계자가 다른 부서로 이동하는 경우, 해당 과제카드 권한이 자동으로 종료되도록 개선
	3. 과제카드함 비전자문서 조회 시 분기별 검색조건 추가
		- 과제카드함 화면에서 비전자문서 조회 시 '년도' 하위 '분기' 선택 조건을 추가하여 분기별로 조회가 가능하도록 개선
??? success "[업무인계인수] 업무인계인수 유의사항 팝업 안내 기능 신설"
	- 서비스공통 > 포털관리 > 운영환경관리 > 과제환경설정 화면에서 시도총괄관리자용 업무인계인수 안내관리 기능을 추가하여, 입력창 및 팝업으로 유의사항을 안내할 수 있도록 개선
	- 업무인계인수 > 인계함 화면에서 인계신청 시 팝업 또는 담당업무 입력창 배경(글자 입력 시 안내 문구는 자동 소멸)에 설정한 유의사항이 안내되도록 개선
??? success "[업무지원] 일반게시판 일괄삭제 기능 추가"
	- 일반게시판 화면에서 선택한 게시판의 운영자 또는 부운영자가 게시물삭제 버튼을 통해 다수의 게시물을 일괄삭제할 수 있도록 기능 개선
??? success "[메모보고] 함께메모 출력 시 참여자 정보 추가"
	- 보고한메모, 보고받은메모 화면의 상세출력 버튼 또는 메모상세 화면의 출력 버튼을 통해 보고서 출력 시, 함께메모이면 수신상황 내역에 보고자·참고자 외 함께메모 참여자 정보가 함께 출력되도록 기능 개선

## 2026년 7월 28일

??? success "[업무인계인수] 조직개편에 따른 업무인계인수 시 최종완료 처리 기능 개선" 
	- 기존에는 입회완료된 업무인계인수 건이 '적용일자(발령일자) 도래', '인수자가 인계자 부서로 이동' 두 조건을 충족하면, 익일 새벽 1시 배치를 통해 자동 반영됨
	- 입회완료된 업무인계인수 건을 조건이 충족되지 않아도 수동으로 최종완료 처리할 수 있는 기능 추가 (행정업무의 운영 및 혁신에 관한 규정 제61조 준수)
	- 해당 기능은 인수자, 입회자 및 시도총괄관리자(업무), 기관관리자(업무), 부서(학교)업무인계인수담당자 권한의 사용자만 사용가능
	- 수동으로 최종완료 처리시 문서가 공람처리 되지 않으며, 인수자가 인계자의 부서로 이동해야지만 과제 권한이 이양됨
	
## 2026년 6월 23일

!!! success "[기록물이관] 기록물 사본 폐기 기능 적용"
	- 기록물 이관이 완료된 문서(사본)를 안전하게 폐기하고 관리할 수 있도록 '기록물이관마감관리' 화면과 '폐기진행현황' 화면을 신규 제공
	- 기록물이관마감관리
		1. 화면설명 : 기록물담당자가 이관 완료된 해당 연도의 미이관 기록물을 확인하고 이관 작업을 최종 마감하는 화면
		2. 화면경로 : 업무관리 > 과제관리 > 기록물이관 > 기록물이관마감관리
		3. 필요권한 : 시도기록물담당자
	- 폐기진행현황
		1. 화면설명 : 총괄관리자가 이관 마감된 생산년도를 대상으로 '조회제한'을 우선 적용한 후, 부서별 폐기 실적 수집 및 물리적 폐기 처리를 관리하는 화면
		2. 화면경로 : 업무관리 > 과제관리 > 기록물이관 > 폐기진행현황 
		3. 필요권한 : 시도총괄관리자(업무)
	- 폐기 작업 전 '조회제한' 설정시 사용자 화면에서 해당 폐기 연도의 문서 조회를 차단하는 기능 제공
??? success "[기록물이관] 대용량 별송파일 처리과 단위 다운로드 기능 추가"
    - 대용량 별송파일 다운로드를 전체 처리과 일괄실행에서 처리과 단위로 수행할 수 있도록 기능 개선
??? success "[일정관리] 일정관리 공개범위 세분화 및 하위 세부기관 업무일정 공유 기능 추가"
	- 교육청일정담당자 권한을 가진 사용자가 일정 작성시 공개범위를 교육청 전체에서 세분화 하여 설정할 수 있도록 개선
	- 공개범위 세분화 선택은 기관분류(시도교육청, 교육지원청, 직속기관, 학교)와 학교급(유치원, 초등학교, 중학교, 고등학교, 특수학교)별 제공
	- 공개범위를 교육청내공개로 선택시 열람 가능한 조직 확인을 위한 열람조직 조회 기능 제공

!!! success "[과제관리] 과제카드 그룹 관리 기능 제공"
	- 부서 내 다수의 과제카드를 업무 성격에 따라 그룹으로 구성하여 효율적으로 관리할 수 있는 기능 신규 제공
	- 업무 성격에 맞는 과제카드 그룹을 생성하여 과제카드를 그룹 단위로 관리할 수 있도록 지원
	- 화면경로 : 업무관리 > 과제관리 > 과제카드관리 > 과제카드그룹관리
	- 필요권한 : 부서·기관·시도 과제카드 담당자
	- 업무처리순서
		1. 과제카드 그룹 등록
		2. 등록된 그룹에 과제카드 일괄 등록
		3. 그룹 내 과제카드 담당자 일괄 지정
