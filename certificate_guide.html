    업무포털 접속 및 인증서 안내

    개요

    업무포털은 교육행정전자서명 인증서로 로그인하는 시스템이므로, 업무를 시작하려면 먼저 인증서를 발급받아야 합니다. 교육행정전자서명 인증서는 교육부 행정전자서명인증센터에서 발급하며, 한국교육학술정보원이 교육부로부터 인증센터 운영을 위탁받아 업무를 수행하고 있습니다. 인증서를 발급받은 후에는 업무포털에서 사용자등록을 수행하여 인증서와 아이디를 연결해야 로그인할 수 있습니다.

    인증서 발급 문의처

    • 교육부 행정전자서명인증센터 홈페이지: www.epki.go.kr
    • 인증센터 대표전화: 053-714-0755
    • 소속기관의 인증담당자는 인증센터 홈페이지의 [고객센터] → [인증담당자 안내] 메뉴에서 확인 가능
    • 업무포털·K-에듀파인 로그인 자체에 대한 문의는 인증센터가 아닌 해당 시스템 상담센터로 연락
    graph LR
  A[인증서 신청서 작성] --> B[등록기관에 공문 발송];
  B --> C[신원확인 및 등록];
  C --> D[참조번호·인가코드 수신];
  D --> E[인증센터에서 인증서 발급];
  E --> F[업무포털 사용자등록];
  F --> G[업무포털 로그인];

    인증서 신청

    인증서는 인증센터 홈페이지에서 신청서 양식을 내려받아 작성한 후, 소속기관을 담당하는 등록기관에 전자공문으로 제출하여 신청합니다. 신청서 양식은 인증센터 홈페이지의 [자료실] → [인증서신청 관련양식] 메뉴에 있으며, 항상 최신 버전을 사용해야 합니다.

    신청서 제출 시 유의사항

    「국가기록원 기록물 관리지침」에 따라 붙임파일인 신청서에는 비밀번호를 설정하지 않아야 합니다. 대신 전자문서시스템의 문서보안 기능이나 열람범위 지정 기능을 활용하시기 바랍니다.

    인증서 종류

    인증서는 사용 주체와 용도에 따라 네 가지로 구분되며, 종류마다 작성하는 신청서 양식이 다릅니다.

    종류 사용 주체 용도
    개인용 개인 업무포털 로그인 등 개인이 수행하는 업무
    전자관인용(기관용) 기관 기관 명의의 전자문서 서명
    특수목적용(업무용) 업무 담당자 특정 업무 단위로 사용하는 인증서
    서버용 서버(컴퓨터) 서버에 설치하여 시스템 간 연계에 사용

    단체 신청서 사용 기준

    • 여러 건을 한 번에 신청할 때에는 종류별 단체 신청서를 사용하며, 신규와 재발급만 신청 가능합니다.
    • 폐지, 효력정지, 효력회복은 반드시 개별 신청서로 신청해야 합니다.
    • 대상이 많은 경우 엑셀 파일의 행을 추가하여 입력하되, 한 파일에 100건 이하로 입력할 것을 권장합니다.
    • 전자공문을 발송할 때 엑셀 파일 원본을 함께 첨부해야 합니다.

    개인용 신청서 작성 방법

    개인용 인증서를 신청하려면 "개인용(개별)신청서"를 작성합니다.

    소속(기관명)

    학교는 상위기관과 학교명을 함께 기재하고, 행정기관은 부서 단위까지 기재합니다. ※ 예시: 서울특별시OO교육지원청 OO중학교, 교육부 디지털교육기획관 디지털인프라담당관

    성명

    신청자의 이름을 기재합니다.

    주민등록번호(외국인등록번호)

    신청자의 주민등록번호 또는 외국인등록번호를 정확하게 기재합니다.

    이메일 및 휴대전화번호

    인증서 발급·재발급 인가, 갱신, 효력정지, 퇴직자 폐지 등의 안내가 이메일과 문자메시지로 발송되므로 정확한 정보를 입력해야 합니다.

    임시비밀번호

    인증서를 발급할 때 참조번호와 인가코드를 조회하면서 입력하는 값으로, 숫자 8자리로만 작성합니다. ※ 12345678은 사용 가능하며, 1234나 123456789처럼 8자리에 못 미치거나 넘는 값은 사용할 수 없습니다.

    종류별 추가 기재 항목

    종류 개인용 항목 외에 추가로 기재하는 항목
    전자관인용(기관용) 사업자등록번호, 기관코드
    특수목적용(업무용) 담당자, 업무명, 사업자등록번호, 기관코드
    서버용 사업자등록번호, 기관코드, 전화번호, 시스템 IP 주소, 인증서활용용도
    • 기관코드는 행정안전부 행정표준코드에 등록된 코드로, 행정표준코드관리시스템(www.code.go.kr)에서 확인합니다. (예시: B550629)
    • 시스템 IP 주소는 서버용 인증서를 설치하는 컴퓨터의 공인 IP를 기재합니다. (예시: 61.108.227.101)
    • 업무명은 특수목적용 신청서에 반드시 기재해야 하며, 업무명칭 외에 이름·직위·신분·기관명은 사용할 수 없습니다. ※ 사용 불가 예시: '이O화', '원격업무김O환', '이사장결재', 'OO학교교장', 'OO고등학교', '사회복무요원' 등

    신청 종류와 재발급·폐지 사유

    신청서의 신청구분 항목에 'v' 또는 '■'로 표시하고, 재발급이나 폐지를 선택한 경우에는 사유 항목도 함께 표시합니다.

    신청 종류 해당하는 상황
    신규 처음으로 인증서를 신청하는 경우
    재발급 비밀번호를 분실했거나 삭제·분실한 인증서를 다시 사용하려는 경우
    폐지 퇴직 등의 사유로 인증서를 무효화하려는 경우
    효력정지 휴직 등의 사유로 인증서의 효력을 일시적으로 정지하려는 경우
    효력회복 효력정지된 인증서를 다시 사용하려는 경우

    효력정지 기간에 유의하세요

    효력정지된 인증서를 6개월(180일) 이내에 효력회복하지 않으면 자동으로 폐지됩니다.

    재발급·폐지 사유 해당하는 상황
    인증정보노출 가입자가 교육행정전자서명 생성키를 노출하거나 분실한 경우
    소속기관변경 부처 간 인사이동으로 기존 부처에서 폐지하고 신규 부처에서 새로 발급받아야 하는 경우
    저장매체파손 및 비밀번호 분실 저장매체 파손, 비밀번호 분실 등으로 생성키를 인식할 수 없는 경우
    기타 인증서 유효기간 만료 등 그 밖의 사유를 직접 기재

    공문 제출처

    작성한 신청서는 소속기관을 담당하는 등록기관(RA) 또는 원격등록기관(LRA)에 전자공문으로 제출합니다.

    개인용 / 전자관인용(기관용) / 특수목적용(업무용)

    신청자(기관) 소속 발급 문의 및 공문 수신기관
    시도교육청, 본청 직속기관, 고등학교 시도교육청
    교육지원청, 유치원, 초등학교, 중학교 교육지원청
    대학교 소속 대학
    공공기관 소속 공공기관
    교육부 및 직속기관, 국립각급학교 한국교육학술정보원

    서버용 / (원격)등록기관용

    구분 신청자(기관) 소속 발급 문의 및 공문 수신기관
    서버용 유치원, 초등학교, 중학교, 고등학교, 교육지원청, 시도교육청, 본청 직속기관 시도교육청
    서버용 그 외 기관 한국교육학술정보원
    원격등록기관용(LRA) 교육지원청 시도교육청
    원격등록기관용(LRA) 그 외 기관 한국교육학술정보원
    등록기관용(RA) RA 등록기관 한국교육학술정보원

    인증담당자가 없는 기관

    대학과 공공기관에 기관 인증담당자가 없는 경우에는 한국교육학술정보원에서 발급합니다. 소속기관의 인증담당자는 인증센터 홈페이지의 [고객센터] → [인증담당자 안내] 메뉴에서 확인할 수 있습니다.

    발급·재발급 신청 절차

    개인용, 전자관인용(기관용), 특수목적용(업무용) 인증서의 발급·재발급 신청은 다음 순서로 진행됩니다.

    1. (신청자) 인증서 신청서를 작성합니다. 신청구분은 발급 또는 재발급으로 선택합니다.
    2. (신청자) 작성한 신청서를 담당 등록기관(RA/LRA)에 전자공문으로 발송합니다.
    3. (등록기관) 공문을 접수한 후 신원확인 절차를 거쳐 사용자 정보를 등록(발급 인가)합니다.
    4. (인증센터) 등록이 완료되면 신청서에 기재한 이메일 주소와 휴대전화번호로 등록·발급 안내 보안메일과 문자메시지가 자동 발송됩니다.
    5. (신청자) 안내받은 참조번호와 인가코드로 인증센터 홈페이지에서 인증서를 발급받습니다.

    효력정지·효력회복·폐지 신청

    • 효력정지와 폐지는 인증센터 홈페이지의 [인증서발급/관리] 메뉴에서 사용자가 직접 수행할 수 있습니다.
    • 효력회복은 사용자가 직접 수행할 수 없으므로, 반드시 신청서를 작성하여 공문으로 발송해야 합니다.
    • 전자서명 키 손상, 인증서 분실, 컴퓨터 포맷 등의 사유로 본인이 직접 폐지할 수 없는 경우에도 신청서를 작성하여 공문으로 발송합니다.
    • 서버용 인증서는 개인용과 달리 원격등록기관(LRA)을 거치지 않고 등록기관(RA)에 신청합니다.

    인증서 발급

    등록기관의 등록 처리가 끝나면 인증센터 홈페이지에서 직접 인증서를 발급받습니다. 발급 화면은 인증센터 홈페이지의 [인증서발급/관리] → [인증서 발급/재발급] 메뉴에 있습니다.

    보안 프로그램 설치

    인증센터 홈페이지에 처음 방문하여 인증서 발급이나 관리 기능을 사용하려면 보안 프로그램을 먼저 설치해야 합니다.

    • 인증서 발급 프로그램은 KCaseAgent_Installer.exe를 실행하여 설치합니다.
    • 키보드 보안 프로그램(nProtect Online Security V1.0)은 설치 화면의 체크박스를 선택하여 함께 설치할 수 있습니다.
    • 자동으로 설치되지 않은 경우 홈페이지 첫 화면의 [바로가기 서비스] → [보안모듈설치] 버튼이나 화면 오른쪽의 [Quick Menu] → 보안프로그램 버튼에서 수동으로 설치합니다.

    키보드 보안 프로그램을 설치하지 않은 경우

    인증서 비밀번호나 주민등록번호 같은 민감정보를 입력할 때 가상키패드가 자동으로 활성화됩니다.

    참조번호와 인가코드 확인

    인증서를 발급하려면 참조번호와 인가코드가 필요합니다. 두 값은 등록기관의 등록 처리가 끝난 후 보안메일로 발송됩니다.

    1. 등록 안내 메일에서 [참조번호/인가코드 확인] 버튼을 클릭합니다.
    2. 신청서에 기재한 임시비밀번호 숫자 8자리를 입력한 후 [확인]을 클릭합니다.
    3. 참조번호와 인가코드를 확인한 후 [인증서 발급 바로가기] 버튼으로 발급 화면에 접속합니다.

    메일을 받지 못했거나 폐쇄망이라 열람할 수 없는 경우

    인증센터 홈페이지의 [인증서 발급/재발급] 페이지에서 [참조번호/인가코드 조회] 버튼을 클릭하고, 신청서에 기재한 임시비밀번호를 입력하면 참조번호와 인가코드를 직접 확인할 수 있습니다.

    참조번호와 인가코드의 사용 기한

    • 등록 안내 메일은 30일간 열람할 수 있으며, 30일이 지나면 참조번호와 인가코드의 사용기간이 만료되어 인증서를 다시 신청해야 합니다.
    • 참조번호와 인가코드는 일회용 값이므로, 인증서를 이미 발급받은 후에는 다시 사용할 수 없습니다.

    개인용 인증서 발급·재발급 절차

    1. 인증센터 홈페이지의 [인증서발급/관리] → [인증서 발급/재발급] 페이지로 이동하여, 개인용 인증서 발급의 [참조번호/인가코드 조회] 버튼을 클릭합니다. 참조번호와 인가코드를 이미 알고 있다면 [인증서발급] 버튼을 클릭하여 바로 진행해도 됩니다.
    2. 이름, 주민등록번호, 임시비밀번호를 입력한 후 [확인] 버튼을 클릭합니다.
    3. 발급에 사용할 참조번호와 인가코드가 표시됩니다.
    4. [발급] 버튼을 클릭하면 인증서 저장매체 선택창이 나타납니다. 저장매체를 선택한 후 [확인] 버튼을 클릭합니다.
    5. 인증서 비밀번호를 입력하고 [확인] 버튼을 클릭합니다.
    6. 사용자 정보가 인증센터 시스템으로 전송되면서 발급이 완료됩니다.

    인증서 비밀번호 생성 조건

    인증서 비밀번호는 발급된 인증서에 암호화되어 저장되므로, 반드시 본인이 직접 입력하고 기억해 두어야 합니다.

    비밀번호 생성 조건

    1. 영문자, 숫자, 특수문자 세 가지를 조합하여 9자리 이상으로 만듭니다.
    2. 3자리 이상 연속되거나 동일한 문자열 또는 숫자는 사용할 수 없습니다. ※ 사용 불가 예시: 123, 111, abc, aaa
    3. 영문자는 대문자와 소문자를 구분합니다.

    인증서 비밀번호는 인증센터에서도 확인할 수 없습니다. 분실한 경우에는 신청서를 공문으로 발송하여 재발급받아야 합니다.

    저장 위치와 파일 구성

    발급이 완료되면 선택한 저장매체에 인증서 파일 4개가 한 쌍으로 저장됩니다. 파일 4개가 모두 있어야 인증서를 정상적으로 사용할 수 있습니다.

    파일 용도
    *_sig.cer 서명용 인증서
    *_sig.key 서명용 키
    *_env.cer 암호화용 인증서
    *_env.key 암호화용 키

    GPKI 폴더의 위치

    GPKI 폴더는 저장매체의 최상위 경로(C:\GPKI)에 있어야 합니다. 바탕화면이나 내 문서 등 다른 폴더 하위(C:\Users\GPKI)에 저장되어 있으면 인증서 선택창에 표시되지 않습니다.

    종류별 발급 정보 비교

    인증서 종류에 따라 발급 화면에서 입력하는 값과 저장 경로, 유효기간이 다릅니다.

    구분 발급 시 입력값 저장 경로 유효기간
    개인용 이름, 주민등록번호, 임시비밀번호 C:\GPKI\Certificate\class2 2년 3개월(27개월)
    전자관인용(기관용) 사업자등록번호, 소속기관, 임시비밀번호 C:\GPKI\Certificate\class1 2년 3개월(27개월)
    특수목적용(업무용) 업무명, 사업자등록번호, 소속기관, 임시비밀번호 C:\GPKI\Certificate\class2 1년 3개월(15개월)
    서버용 사업자등록번호, IP, 임시비밀번호 C:\GPKI\Certificate\class1 2년 3개월(27개월)
    • 저장매체로 이동식 디스크를 선택한 경우에는 이동식디스크:\GPKI\Certificate\class1 또는 class2 경로에 저장됩니다.
    • 전자관인용과 특수목적용 인증서를 발급할 때에는 소속된 기관의 상위기관을 먼저 선택한 후 소속기관명을 입력하여 검색합니다.
    • 서버용 인증서는 저장된 파일 4개를 서버로 옮겨 설치하며, 설치 위치는 해당 인증서를 사용하는 응용프로그램의 안내를 따릅니다.

    인증서 관리

    발급받은 인증서는 유효기간에 맞추어 갱신하고, 상황에 따라 효력정지·폐지·키갱신을 수행합니다. 관련 기능은 모두 인증센터 홈페이지의 [인증서발급/관리] 메뉴에 있습니다.

    인증서 갱신

    인증서의 유효기간이 만료되기 전에 갱신하면 신청서를 다시 제출하지 않고 계속 사용할 수 있습니다.

    1. 인증센터 홈페이지의 [인증서발급/관리] → [갱신] 페이지로 이동하여 [인증서 갱신] 버튼을 클릭합니다.
    2. 갱신할 인증서를 선택하고 인증서 암호를 입력한 후 [확인] 버튼을 클릭합니다.
    3. 갱신이 완료됩니다.

    유효기간 만료 안내

    • 교육행정전자서명 인증서의 유효기간은 발급 후 2년 3개월(27개월)이며, 특수목적용 인증서는 1년 3개월(15개월)입니다.
    • 유효기간 만료 90일 전부터 자동으로 안내합니다. 신청서에 기재한 이메일과 휴대전화번호로 90일 전과 15일 전 두 차례 안내가 발송됩니다.
    • 서비스 웹사이트에 로그인할 때에도 만료 도래 사실이 팝업으로 안내됩니다.

    갱신 시 주의사항

    갱신을 진행한 인증서만 정상적으로 사용할 수 있습니다. 다른 PC나 저장매체에 보관 중인 기존 인증서는 폐지 상태가 되어 사용할 수 없으므로, 갱신한 인증서를 다시 복사해서 사용해야 합니다.

    인증서 키갱신

    인증서가 유출된 것으로 의심될 때 공개키쌍을 새로 생성하여 기존 인증서를 사용할 수 없게 만드는 기능입니다.

    1. [인증서발급/관리] → [키갱신] 페이지로 이동하여 [인증서 키갱신] 버튼을 클릭합니다.
    2. 키갱신할 인증서를 선택하고 인증서 암호를 입력한 후 [확인] 버튼을 클릭합니다.
    3. 키갱신이 완료됩니다.

    키갱신의 특징

    • 키갱신은 인증서의 유효기간과 관계없이 언제든지 수행할 수 있으며, 키갱신을 하더라도 남은 유효기간은 변동되지 않습니다.
    • 갱신과 마찬가지로 키갱신을 진행한 인증서만 사용할 수 있으므로, 다른 저장매체의 인증서는 키갱신한 인증서로 다시 복사해야 합니다.

    효력정지와 효력회복

    휴직 등의 사유로 업무를 수행하지 않는 동안 인증서를 사용 중지 상태로 만드는 기능입니다.

    1. [인증서발급/관리] → [효력정지] 페이지로 이동하여 [인증서 효력정지] 버튼을 클릭합니다.
    2. 효력정지할 인증서를 선택하고 인증서 암호를 입력한 후 [확인] 버튼을 클릭합니다.
    3. 효력정지가 완료됩니다.

    효력회복은 직접 수행할 수 없습니다

    효력정지된 인증서는 담당 등록기관(RA/LRA) 관리자에게 공문으로 효력회복을 신청해야만 다시 사용할 수 있습니다. 또한 효력정지 후 6개월(180일) 이내에 효력회복하지 않으면 인증서가 자동으로 폐지됩니다.

    효력정지를 하지 않았는데 인증서가 효력정지 상태입니다.

    효력정지는 인증서 소유자뿐 아니라 담당 RA/LRA 관리자도 수행할 수 있습니다. 해당 사유로 관리자가 처리한 경우이므로 담당 RA/LRA 관리자에게 문의하시기 바랍니다. 담당자 정보는 인증센터 홈페이지의 [고객센터] → [인증담당자 안내] 메뉴에서 확인할 수 있습니다.

    인증서 폐지

    인증서가 유출된 것으로 의심되거나, 비밀번호를 분실했거나, 퇴직한 경우에는 인증서를 폐지하여 더 이상 사용할 수 없도록 무효화합니다.

    1. [인증서발급/관리] → [폐지] 페이지로 이동하여 [인증서 폐지] 버튼을 클릭합니다.
    2. 폐지할 인증서를 선택하고 인증서 암호를 입력한 후 [확인] 버튼을 클릭합니다.
    3. 폐지 여부를 재확인하고 폐지 사유를 선택합니다.
    4. 폐지가 완료됩니다.

    폐지된 인증서는 복구되지 않습니다

    인증서를 다시 사용하려면 재발급 신청서를 공문으로 발송하여 새로 발급받아야 합니다. PC 포맷이나 저장매체 파손 등으로 인증서를 분실한 경우에는 담당 RA/LRA 관리자에게 폐지를 신청하거나, 재발급을 신청하면 기존 인증서가 폐지됩니다.

    인증서 관리 기능

    인증센터 홈페이지의 [인증서발급/관리] → [관리기능] 페이지에서 다음 기능을 사용할 수 있습니다.

    인증서 검증

    발급받은 인증서가 유효한지 확인합니다. 인증서를 선택한 후 [인증서 보기/검증] 버튼을 클릭하면 정상·효력정지·폐지 등의 상태를 확인할 수 있습니다.

    인증서 신원확인(VID 검증)

    인증서의 신원을 확인합니다. 인증서 선택 후 암호를 입력하고, 개인용은 주민등록번호를, 특수목적용과 기관용은 사업자등록번호를 하이픈 없이 입력합니다.

    인증서 백업

    발급받은 인증서를 USB 메모리나 외장하드 등 다른 저장매체로 복사합니다. 복사할 인증서를 선택하고 대상 저장매체를 지정한 후 비밀번호를 입력하면 복사가 완료됩니다.

    인증서 비밀번호 변경

    현재 비밀번호와 새 비밀번호를 입력하여 변경합니다. 선택한 인증서의 비밀번호만 변경되며, 다른 PC나 저장매체에 있는 인증서의 비밀번호는 변경되지 않습니다.

    인증서 형식변환

    인증서를 PFX 파일로 내보내거나, PFX 파일을 가져와 저장매체에 저장합니다. 내보낼 때는 저장 경로를 지정하고 인증서 비밀번호를 입력하며, 가져올 때는 PFX 파일과 저장할 대상 매체를 선택합니다.

    인증서 삭제

    선택한 저장매체에서 인증서를 삭제합니다. 인증서를 폐지하는 것이 아니라 해당 저장매체에서만 제거하는 기능입니다.

    사용자 정보 확인

    전자서명인증시스템에 등록되어 있는 사용자 정보를 확인합니다. 인증서를 선택하고 암호를 입력하면 정보가 표시됩니다.

    인증서 유출이 의심되는 경우의 처리 순서

    비밀번호만 변경해서는 다른 저장매체의 인증서가 그대로 사용될 수 있습니다. 먼저 [인증서 키갱신]을 수행하여 다른 저장매체의 인증서를 무효화한 후 비밀번호를 변경하시기 바랍니다.

    업무포털 사용자등록과 로그인

    인증서를 발급받았다면 업무포털에서 사용자등록을 수행하여 인증서와 아이디를 연결해야 합니다. 사용자등록을 마친 후에는 인증서로 업무포털에 로그인합니다.

    사용자등록

    업무포털에 접속하여 인증서를 등록하고 아이디를 생성하는 기능입니다. 업무포털 메인화면에서 [사용자 등록] 버튼을 클릭하여 시작합니다.

    1. 사용자 등록 팝업에서 사용자 구분을 선택합니다. 교원과 교직원은 인사기록 대상자를, 외부직원은 인사기록 비대상자를 선택합니다.
    2. 이름을 입력한 후 [소속 조회] 버튼을 클릭합니다.
    3. 조직명을 검색하여 소속을 등록합니다.
    4. [사용자 조회] 버튼을 클릭하여 이름, 소속, 직위 정보를 확인합니다.
    5. 같은 소속 안에 동명이인이 있는 경우에는 고유번호 입력창이 나타납니다. 고유번호는 시도 나이스 담당자나 인사 담당자에게 문의하여 확인합니다.
    6. 사용자 조회가 완료되면 인증서를 선택하고 인증서 비밀번호를 입력합니다.
    7. 업무포털과 나이스에서 사용할 아이디를 입력합니다.
    8. [중복체크] 버튼을 클릭하여 아이디의 사용 가능 여부를 확인합니다.
    9. 외부사용자로 등록하는 경우에는 [보안서약서] 버튼을 클릭하여 팝업창에서 동의해야 사용자등록을 진행할 수 있습니다.
    10. 보안서약서 팝업창에서 동의한 후 [확인] 버튼을 클릭하면 이전 화면의 동의 항목이 체크됩니다.

    사용자등록 시 유의사항

    • 내부사용자는 나이스 인사 업무에 인사기록이 등록되어 있지 않으면 사용자등록을 진행할 수 없습니다.
    • 아이디를 생성할 때 주민등록번호 앞자리 등 개인정보는 아이디에 포함할 수 없습니다.

    인증서변경

    기존 사용자에게 등록되어 있는 인증서를 다른 인증서로 변경하는 기능입니다. 인증서를 재발급받거나 갱신한 경우에는 이 기능으로 인증서를 변경해야 로그인할 수 있습니다.

    1. 사용자 아이디를 입력한 후 [조회] 버튼을 클릭합니다. 정상적으로 조회되면 안내 메시지가 표시됩니다.
    2. [인증서 선택] 버튼을 클릭하고 변경할 인증서의 비밀번호를 입력하여 인증서를 등록합니다.

    '사용자와 인증서 정보가 일치하지 않습니다.' 메시지가 표시됩니다.

    • 내부사용자: 인사정보에 등록된 주민등록번호(외국인등록번호)와 인증서를 신청할 때 기재한 번호가 일치하지 않는 경우입니다.
    • 외부사용자: 나이스 외부사용자 정보에 등록된 사업자등록번호와 인증서를 신청할 때 기재한 번호가 일치하지 않는 경우입니다.
    • 번호 문제가 아니라면 전자서명인증센터에 접속하여 정상적인 인증서인지 검증해 보시기 바랍니다.

    아이디(ID) 찾기

    주민등록번호나 사업자등록번호로 사용자의 아이디를 조회하는 기능입니다. [인증서변경] → [아이디(ID)찾기] 경로에서 사용합니다.

    1. [아이디 찾기] 버튼을 클릭합니다.
    2. 사용자 구분을 선택합니다.
    3. 내부사용자: 교원, 일반직, 교육공무직 등
    4. 외부사용자: 외부직원, 기관마스터, 대입사용자 등
    5. 내부사용자는 주민등록번호를 입력하고, 외부사용자는 사업자등록번호와 휴대전화번호, 이메일을 입력한 후 [조회] 버튼을 클릭합니다.
    6. 정상적으로 조회되었다는 메시지와 함께 사용자 아이디를 확인할 수 있습니다.

    로그인

    발급받은 인증서로 업무포털에 통합 로그인합니다.

    1. [교육행정 전자서명 인증서 로그인] 버튼을 클릭합니다.
    2. 인증서를 선택한 후 인증서 암호를 입력합니다.

    '업무포털에 등록되지 않았거나 사용이 중지(종료)된 인증서입니다.' 메시지가 표시됩니다.

    • 기존 사용자: 아이디 사용 기간이 만료되었거나 미사용으로 처리된 경우이므로 기관마스터에게 문의합니다. 퇴직한 사용자는 인사담당자에게 인사기록 처리 여부를 확인합니다. 인증서를 재발급하거나 갱신한 경우에는 업무포털에서 인증서변경을 수행합니다.
    • 타시도 파견 사용자: 인사시스템에서 업무포털로 연계 재전송 처리를 해야 합니다.

    '사용자등록 대상이 아닙니다. 사용자 등록여부를 확인 후 다시 시도해 주십시오' 메시지가 표시됩니다.

    신규 사용자나 전입 사용자에게 표시되는 메시지입니다. 사용자등록 절차를 수행한 뒤에 로그인하시기 바랍니다.

    인증서 비밀번호를 여러 번 틀렸습니다.

    인증서 비밀번호 오류 횟수가 초과된 경우에는 브라우저를 종료하고, 재접속 제한기간이 지난 후 새 창을 열어 캡챠 인증을 진행한 다음 다시 로그인합니다.

    겸임 사용자와 외부사용자의 로그인

    • 겸임 대상자인 경우 로그인 시 겸임 선택창이 열립니다.
    • 외부사용자는 최신 일자의 보안서약서에 동의하지 않은 상태라면 팝업창이 표시되며, 동의를 체크하고 확인해야 로그인할 수 있습니다.

    업무포털 개인설정

    업무포털의 화면과 개인 정보를 사용자가 직접 설정하는 기능입니다.

    스킨설정

    [개인설정] → [스킨설정] 경로에서 화면에 사용할 배경색을 설정합니다.

    1. 사용할 배경색을 선택합니다.
    2. 저장 버튼을 클릭하여 배경색을 저장합니다.

    업무바로가기설정

    [개인설정] → [업무바로가기설정] 경로에서 메인화면에 표시할 업무바로가기를 설정합니다.

    1. 업무바로가기로 설정할 대상을 선택합니다. 마스터 관리자가 지정한 필수 업무바로가기와 사용자가 직접 선택할 수 있는 업무바로가기가 구분되어 표시됩니다.
    2. 저장 버튼을 클릭하여 업무바로가기를 저장합니다.

    개인정보조회

    [개인설정] → [개인정보조회] 경로에서 개인 정보를 조회하고 관리합니다.

    1. 담당업무, 직원검색허용 여부, 개인사진 표시 여부를 설정합니다.
    2. 저장 버튼을 클릭하여 개인정보를 저장합니다.
    설정 항목 설정에 따른 결과
    담당업무 설정한 담당업무가 화면에 표시됩니다.
    직원검색허용 허용과 비허용에 따라 직원검색 결과 노출 여부가 달라집니다.
    개인사진표시여부 표시와 미표시에 따라 개인사진 노출 여부가 달라집니다.

    개인접속이력조회

    [개인설정] → [개인접속이력조회] 경로에서 본인의 접속이력을 조회합니다.

    1. 검색기간과 비정상종료 여부 등 조회 조건을 설정합니다.
    2. 조회 버튼을 클릭하여 개인접속이력을 조회합니다.
    3. 로그인 아이디, 성명, 소속조직, 로그인 시각, 로그아웃 시간, 접속유형, 접속주소가 조회됩니다.
    4. 필요한 경우 엑셀 다운로드 버튼을 클릭하여 개인접속이력을 내려받습니다.

    겸임선택

    겸임 대상자가 주로 사용할 조직을 등록하는 기능입니다.

    1. 겸임이 있는 대상자에게만 [겸임선택] 버튼이 표시됩니다.
    2. 버튼을 클릭하면 겸임내역이 조회됩니다.
    3. 주사용 조직을 선택한 후 저장합니다.
    4. 초기화 버튼을 클릭하면 주사용 조직이 초기화됩니다.

    주사용 조직 설정의 효과

    주사용 조직을 선택하여 저장하면 이후 로그인할 때 겸임 선택창이 생략됩니다. 초기화 버튼을 클릭하면 주사용 조직이 초기화되므로 이후 로그인할 때 겸임 선택창이 다시 열립니다.

    다크모드

    [다크모드] 버튼을 클릭하면 업무포털 메인화면 전체가 다크모드로 전환됩니다.

    자주 묻는 질문

    신청과 발급

    교육행정전자서명 인증서 신청은 어떻게 하나요?

    인증센터 홈페이지(www.epki.go.kr)에서 신청서를 내려받아 작성한 후, 소속기관을 담당하는 등록기관으로 전자공문을 제출하시면 됩니다. 공문 수신처는 이 문서의 공문 제출처 항목에서 확인할 수 있으며, 신청 관련 문의는 소속기관 인증담당자에게 하시기 바랍니다.

    우리기관의 교육행정전자서명 인증담당자는 누구인가요?

    인증센터 홈페이지의 [고객센터] → [인증담당자 안내] 메뉴에서 검색할 수 있습니다.

    소속기관이 변경되면 인증서를 재발급 받아야 하나요?

    동일 시도교육청 또는 동일 기관 안에서 소속이 변경된 경우에는 재발급받지 않아도 그대로 사용할 수 있습니다.

    • 재발급 불필요: OO교육청 → OO교육청 △교육지원청, OO교육청 C초등학교 → OO교육청 D고등학교
    • 재발급 필요: OO교육청 → □□교육청, OO교육청 a초등학교 → □□교육청 b교육지원청

    타 시도교육청이나 타 시도교육청 소속기관(초·중·고, 대학 등)으로 전출입한 경우에는 변경된 소속으로 재발급받으셔야 합니다.

    기관용 인증서 등의 업무담당자가 퇴직, 인사이동 등으로 변경되었을 경우 재발급 받아야 하나요?

    전자관인용, 특수목적용, 서버용, (원격)등록기관용 인증서의 업무 담당자가 변경된 경우에는 기존 인증서를 폐지한 후 신규 담당자로 변경하여 재발급을 신청하셔야 합니다.

    인증서 발급/재발급 요청 후 참조번호와 인가코드를 메일로 받지 못했습니다.

    인증센터 홈페이지에서 직접 조회하실 수 있습니다.

    1. 홈페이지 상단 메뉴 [인증서발급/관리] → [발급/재발급]을 클릭합니다.
    2. 인증서 발급의 [참조번호/인가코드 조회]를 클릭합니다.
    3. 신청서에 기재한 이름, 주민등록번호, 임시비밀번호를 입력한 후 [확인]을 클릭합니다.
    4. 입력한 정보가 정확하면 참조번호와 인가코드를 확인할 수 있습니다.

    참조번호와 인가코드는 인증서 발급을 완료한 후에는 다시 사용할 수 없습니다.

    인증서 발급/재발급 후 인증서 파일은 어디에 저장되나요?

    저장매체를 하드디스크로 선택한 경우 다음 경로에 저장됩니다.

    • 개인용, 특수목적용: C:\GPKI\Certificate\class2
    • 기관용, 서버용: C:\GPKI\Certificate\class1

    비밀번호

    인증서 비밀번호를 분실했을 경우 어떻게 해야 하나요?

    인증서 비밀번호는 암호화되어 관리되기 때문에 교육부 행정전자서명인증센터에서도 확인할 수 없습니다. 비밀번호를 분실하신 경우에는 인증서를 재발급받으셔야 합니다.

    인증서 비밀번호를 변경하려면 어떻게 해야 하나요?

    인증센터 홈페이지에서 변경할 수 있습니다.

    1. 홈페이지 상단 메뉴 [인증서발급/관리] → [관리기능]을 클릭합니다.
    2. [비밀번호 변경] → [바로가기]를 클릭합니다.
    3. 인증서 선택창에서 인증서를 선택한 후 비밀번호 변경을 클릭합니다.
    4. 비밀번호를 변경하면 변경 완료 메시지가 표시됩니다.

    임시비밀번호를 모를 경우 어떻게 해야 하나요?

    임시비밀번호는 인증서 신청서를 작성할 때 기재한 숫자 8자리입니다. 임시비밀번호를 모르는 경우에는 작성하신 신청서를 확인하거나 소속기관 인증담당자에게 문의하시기 바랍니다.

    인증서 상태

    인증서 유효기간이 지나면 인증서가 자동으로 폐지되나요?

    유효기간(2년 3개월, 특수목적용은 1년 3개월)이 지나면 해당 인증서는 사용할 수 없게 됩니다. 인증서를 다시 사용하시려면 신규 또는 재발급을 신청하시기 바랍니다.

    유효기간이 남아있는데 인증서가 폐지된 것으로 확인됩니다.

    다음 세 가지 경우를 확인해 보시기 바랍니다.

    1. 사용자 또는 RA/LRA 인증담당자가 인증서를 폐지했거나 재발급을 처리 중인 경우에는 유효기간과 관계없이 폐지됩니다. 퇴직자 현행화로 인증서가 자동 폐지되는 경우도 있습니다. 폐지된 경우에는 재발급받으셔야 합니다.
    2. 인증서를 여러 매체에 복사하여 사용 중인 경우, 한 저장매체의 인증서를 갱신·키갱신·재발급하면 다른 저장매체의 인증서는 폐지된 것으로 확인됩니다. 갱신하거나 재발급한 인증서를 다른 매체로 복사하여 사용하시기 바랍니다.
    3. PC의 날짜와 시간이 현재 시각과 일치하지 않는 경우에도 이러한 오류가 발생할 수 있습니다. PC의 날짜와 시간을 현재 시각으로 설정해 주시기 바랍니다.

    로그인 시 인증서 선택 창에 인증서가 보이지 않습니다.

    인증서가 정상적인 경로에 저장되지 않았거나, 인증서가 만료되었거나, 시스템 언어가 한국어가 아닌 경우입니다.

    1. 저장 경로 확인: 해당 경로 안에 *_sig.cer, *_sig.key, *_env.cer, *_env.key 파일 4개가 한 쌍으로 있어야 합니다. 파일 4개가 모두 있지 않으면 인증서를 재발급받으셔야 합니다. 개인용과 특수목적용은 C:\GPKI\Certificate\class2\, 기관용은 C:\GPKI\Certificate\class1\ 경로를 확인합니다. GPKI 폴더는 저장매체의 최상위 경로에 있어야 하며, 바탕화면이나 내 문서 하위에 있으면 인증서 선택창에 표시되지 않습니다.
    2. 유효기간 확인: 인증서 저장 경로에서 *_sig.cer 또는 *_env.cer 파일을 더블 클릭한 후 [자세히] 탭의 유효기간(끝) 항목을 확인합니다.
    3. 시스템 언어 확인: 제어판 → 국가 또는 지역 → 관리자 옵션 → 시스템 로캘 변경에서 한국어(대한민국)로 설정합니다.

    업무포털 로그인

    나이스 업무포털, K-에듀파인, 행정정보공동이용 로그인이 안 되는 경우 어떻게 해야 하나요?

    해당 시스템의 로그인 문제는 교육부 행정전자서명인증센터에서 답변드리기 어려운 내용입니다. 각 시스템의 상담센터로 문의하시기 바랍니다.

    오류 메시지 해결 방법

    인증서를 발급하거나 사용하는 과정에서 발생하는 오류 메시지의 처리 방법입니다. 해당하는 항목을 펼쳐서 확인하시기 바랍니다.

    '참조번호 또는 인가코드가 맞지 않습니다.' (발급·재발급 시)

    두 가지 경우가 있습니다.

    1. 참조번호와 인가코드를 잘못 입력한 경우: 값을 다시 한 번 정확하게 입력해 보시기 바랍니다.
    2. 이미 인증서를 발급받은 경우: 참조번호와 인가코드는 일회용 값이므로 다시 사용할 수 없습니다. 인증서가 이미 정상적으로 발급 완료된 것은 아닌지 확인해 보시기 바랍니다.
    '40961:' 또는 '알 수 없는 에러' (발급·재발급·(키)갱신 시)

    nProtect Online Security 등의 보안프로그램이 KCaseLib.exe 프로세스를 차단한 경우이므로 인터넷 브라우저를 재시작합니다.

    1. 윈도우 작업표시줄에서 인터넷 브라우저 아이콘을 우클릭하여 모든 브라우저(Edge, Chrome 등) 창을 닫습니다.
    2. 새로운 브라우저를 실행하여 인증센터 홈페이지에 접속한 후 발급이나 갱신을 다시 진행합니다.
    '40962: 파일의 권한 또는 숨김 여부 등으로 인하여 작업을 수행 할 수가 없습니다.' (발급·재발급·(키)갱신 시)

    USB 등 이동식 저장매체에 인증서를 저장할 때, 해당 매체가 매체제어 솔루션이나 보안프로그램으로 인해 쓰기금지 상태이거나 수정 권한이 없어 저장에 실패하는 경우입니다. 저장매체를 선택할 때 하드디스크를 선택하거나, 이동식 저장매체의 상태를 확인해 보시기 바랍니다.

    '사용자 정보가 존재하지 않습니다.' (참조번호·인가코드 조회 시)

    두 가지 경우가 있습니다.

    1. 입력한 정보가 정확한지 확인합니다. 임시비밀번호는 신청서 작성 시 기재한 숫자 8자리입니다.
    2. 해당 참조번호와 인가코드로 이미 인증서를 발급받은 경우입니다. 일회용 값이므로 다시 사용할 수 없습니다.
    '패스워드를 입력해주세요' (비밀번호를 설정했는데도 표시되는 경우)

    키보드 보안 모듈이 정상적으로 로딩되지 않은 경우입니다. 인증센터 홈페이지에서 키보드 보안모듈(NOS)을 설치하시기 바랍니다.

    '40964: 인증서 저장에 실패 하였습니다' ((키)갱신 시)

    인증서 발급 시 생성된 파일 4개가 모두 정상적으로 저장되어 있어야 갱신과 키갱신을 진행할 수 있습니다. 인증서 저장 경로에 *_sig.cer, *_sig.key, *_env.cer, *_env.key 파일 4개가 한 쌍으로 있는지 확인하시고, 파일이 모두 있지 않으면 인증서를 재발급받으셔야 합니다.

    • 개인용, 특수목적용: C:\GPKI\Certificate\class2
    • 기관용: C:\GPKI\Certificate\class1
    '32797 : KCaseAgent 버전이 일치 하지 않습니다.' (보안프로그램 설치·삭제 시)

    인증센터 홈페이지 외에 열려 있는 브라우저 창을 모두 닫고 보안프로그램(KCaseAgent)을 재설치합니다.

    1. PC를 재부팅한 후 제어판 → 프로그램 및 기능에서 KCaseAgent를 제거합니다.
    2. C:\Program Files (x86)\KSIGN\KCase 또는 C:\Program Files\Ksign\KCase 경로로 이동하여 KCase 폴더를 삭제합니다.
    3. 인증센터 홈페이지에서 보안모듈(KCaseAgent)을 재설치합니다.
    '인증서 비밀번호가 일치하지 않습니다.' (비밀번호를 입력했는데도 표시되는 경우)

    다음 순서로 확인해 보시기 바랍니다.

    1. 키보드의 Caps Lock 또는 Num Lock 키가 활성화되어 있지 않은지 확인합니다. 메모장 등에서 대소문자, 숫자, 특수문자가 올바르게 입력되는지 확인해 보시기 바랍니다. 비밀번호를 너무 빠르게 입력하면 키보드 보안 솔루션이 오동작할 수 있습니다.
    2. 인증센터 홈페이지의 [인증서 신원확인(VID 검증)] 기능으로 입력한 비밀번호가 맞는지 확인할 수 있습니다. 상단 메뉴 [인증서발급/관리] → [관리기능]에서 [인증서 신원확인(VID 검증)] → [바로가기]를 클릭한 후, 인증서를 선택하고 비밀번호를 입력한 다음 식별정보를 입력합니다. 식별정보는 개인용의 경우 주민등록번호, 특수목적용과 기관용의 경우 사업자등록번호이며 하이픈은 제외하고 입력합니다. 비밀번호가 맞으면 "인증서 신원이 확인 되었습니다."라는 메시지가, 틀리면 "인증서 비밀번호가 올바르지 않습니다."라는 메시지가 표시됩니다.
    3. 키보드 보안모듈 등 PC 환경 오류로 비밀번호가 잘못 입력될 수 있습니다. 실행 중인 브라우저를 모두 종료하거나 PC를 재시작한 후 다시 로그인을 시도해 보시기 바랍니다.

    비밀번호를 분실하신 경우에는 인증서를 재발급받으셔야 합니다.

    '16389 : 서명용 개인키를 읽는데 실패하였습니다.' (인증서 로그인 시)
    1. 인증서 저장 경로에 *_sig.cer, *_sig.key, *_env.cer, *_env.key 파일 4개가 한 쌍으로 있는지 확인합니다. 파일이 모두 있지 않으면 인증서를 재발급받으셔야 합니다. 개인용과 특수목적용은 C:\GPKI\Certificate\class2\, 기관용은 C:\GPKI\Certificate\class1\ 경로입니다.
    2. 인증서 파일의 확장자가 임의의 영문자 조합(.jcowwkrdu, .ymdmf, .vbdrj 등)으로 변경되어 있다면 사용 중인 PC가 랜섬웨어에 감염되었을 수 있으므로, PC 관리자를 통해 점검이 필요합니다.
    'KCaseAgent가 설치되어 있지 않습니다. 확인버튼을 누르시면 설치파일을 다운로드합니다.'

    교육부 행정전자서명인증센터에서 제공하는 보안모듈을 설치해야 인증서 발급과 사이트 이용이 가능합니다. 설치를 완료한 후 페이지를 새로고침(F5)하면 인증서 발급과 재발급 등을 수행할 수 있습니다.
